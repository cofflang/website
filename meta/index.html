how this website is built and how to use it

how the site is built

the site is written by hand as static HTML and CSS, for now.

how to use it

longer articles use margin notes. a small raised marker (like this onethis is a margin note. click the marker again to put it away. the whole mechanism is pure CSS, so it keeps working with JavaScript switched off.) opens a note when you click it, and closes it when you click again. links that leave the site are marked with a small so you know before you follow them, and cross-references that stay on the site carry a small .

some names point at documentation that is written but not yet published. these are shown in muted text with a small and do not lead anywhere for now. the operating-system internals are being gone through by hand before they are opened up, so their links are held back this way in the meantime.
